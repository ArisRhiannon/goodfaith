# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) v2.1.

Be respectful and constructive. Harassment and abusive behavior are not tolerated.
Report unacceptable behavior to the maintainer privately (see `SECURITY.md` for a private
channel). Maintainers may remove contributions or contributors that violate this code.
