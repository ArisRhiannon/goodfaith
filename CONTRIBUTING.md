# Contributing to goodfaith

Thanks for your interest in contributing!

## Workflow

1. Fork the repo and create a branch: `feat/your-feature` or `fix/your-bug`.
2. Make your change, with tests where applicable.
3. Run the test suite and make sure CI passes.
4. Use [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`…).
5. Open a pull request into `main` describing what changed and why.

## Code style

Keep changes focused and documented. Add an entry to `CHANGELOG.md` under **Unreleased**.
